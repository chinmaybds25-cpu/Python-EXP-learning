Develop a Simple Chatbot using Python that interacts with users by responding to predefined questions and greetings. The chatbot should accept user input continuously and identify common greetings and questions using appropriate Python control structures. It should provide a suitable response for recognized inputs and display a default message for unknown inputs. The chatbot must continue the conversation until the user chooses to exit by entering commands such as bye, exit, or quit. The program should demonstrate fundamental Python programming concepts, including input/output, strings, conditional statements, loops, functions, and control structures. This utility is aligned with Module 1: Fundamental of Python Programming / Control Structure specified in the practical assessment document.
